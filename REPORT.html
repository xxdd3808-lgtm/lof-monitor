一、背景与初衷

项目初衷是"如何真正赚到钱"。华宝油气 (162411) 是 QDII-LOF，存在场内价与净值的折溢价。理论上可以套利：

  • 溢价套利（申购->卖出）：但基金常年暂停申购（每日上限 10 元），通道基本堵死
  • 折价套利（买入->赎回）：赎回开放，但 QDII 净值滞后 + 赎回费高 + 美股当晚波动风险

原项目只做了 IOPV 估算，缺少"能不能做"和"值不值得做"两层判断。本次 P1-P5 补全这两层，并用历史回测验证策略有效性。

二、P1 - 折价套利收益计算器 已完成

功能

基于当前实时折价，自动计算各持有期档位的真实收益，让用户一眼看出"这个折价能不能做"。

输出

  • 各档赎回费收益表：T+0(1.5%) / 7天(0.75%) / 30天(0.5%) / 1年(0%) 四档，每档算出：
    • 毛收益（美股持平时的纯折价收敛）
    • 净收益（扣赎回费+佣金后）
    • 盈亏平衡美股跌幅：美股跌多少就从赚变亏
  • 情景分析表：美股当晚涨跌 -8% ~ +5% 各情景下的实际收益
  • 结论判定：折价 <3% 不建议 / 3-5% 风险大 / 5-8% 不错 / >8% 值得关注

核心公式

盈亏平衡美股跌幅 = [1 - (1 + 赎回费 + 佣金) × (1 + 折价率)] / 仓位系数 w

价值

直接回答用户"看到 3% 折价能不能做"的问题。3% 折价 + T+0 赎回（1.5%费），安全垫仅 1.5%，美股跌 1.63% 就亏。结论：不值得做。

三、P2 - 美股盘前/原油先行指标 已完成

功能

A 股收盘后美股才开盘。折价套利的赎回净值取决于当晚美股走势。本模块提供先行指标，帮助预判今晚美股方向，决定是否在 15:00 前提交赎回。

指标列表

  • WTI 原油期货 (CL=F)：全球 24h 交易，A 股时段有亚盘价格，油气股最直接先行指标
  • Brent 原油期货 (BZ=F)：欧洲基准油价
  • 标普500期货 (ES=F) / 纳指期货 (NQ=F)：大盘情绪
  • XOP 油气ETF：最直接的底层资产方向
  • 美元指数 (DXY)：美元走强压制油价

附加

WTI/Brent 近 5 日走势图（plotly），帮助判断原油短期趋势。

决策规则

折价套利时，若 WTI 原油期货亚盘跌 > 2%，今晚 XOP 大概率跟跌，赎回净值风险大，建议放弃或等原油企稳再赎回。

四、P3 - 历史套利回测（核心） 已完成

功能

遍历历史每个交易日，模拟"折价超阈值时买入 + 当日赎回"，用事后实际净值算真实收益。用数据回答"折价套利到底能不能赚钱"。

回测逻辑

对每个交易日 D：
  信号 = close_D / nav_{D-1} - 1   # 决策时看到的折价
  if 信号 <= -阈值:
    买入价 = close_D
    赎回净值 = nav_D              # 当日实际净值（事后已知）
    毛收益 = nav_D / close_D - 1
    净收益 = 毛收益 - 赎回费 - 佣金

输出

  • 各阈值（3%/5%/8%/10%）× 各赎回费档（1.5%/0.75%/0.5%）的回测统计表
  • 累计收益曲线（plotly）
  • 单笔收益分布直方图
  • 完整交易明细表
  • 自动结论判定（能赚/勉强/赚不到）

数据源

三重 fallback：akshare Sina 源 -> 东财 K 线 API -> yfinance，确保数据获取可靠性。

关键结论

❌ T+0 折价套利不赚钱。

1.5% 的惩罚性赎回费吃掉了大部分折价。3%+ 折价 + T+0 赎回，5 笔交易胜率仅 20%，平均亏损 0.15%。唯一的 5%+ 折价机会（2026-04-08，折价 6.16%），T+0 赎回后净亏 0.12%。

⚠️ 延长持有期有边际收益，但机会极少。

3%+ 折价 + 持有 30 天后赎回（费 0.5%），5 笔交易胜率 60%，平均 +0.85%。但 13 个月只有 5 次机会，且持有期间承受美股方向风险。不是套利，是"折价 + 看好油气"的价值投资。

✅ 真正的机会在溢价端。

历史最大溢价 +21.12%，均值 +0.33%（轻微溢价）。如果你已经持有华宝油气，溢价时场内卖出、折价时买回，是利用折溢价波动增强收益的现实路径。但这需要长期持有底仓，不是无风险套利。

一句话总结

折价套利对普通投资者是"看起来很美"的陷阱。1.5% 赎回费 + 美股当晚波动盲盒 + 大折价极罕见（13 个月仅 1 次 >5%），期望收益为负。项目的真正价值是用数据告诉你别做，以及在溢价时提醒已持有者卖出。

八、开发过程中发现并修复的问题

1. 回测数据源问题

问题：ak.fund_lof_hist_em() 在本地环境被代理拦截（2.push2.eastmoney.com 返回 502）。东财 K 线 API 也不稳定。yfinance 被 Yahoo 限频。

修复：三重 fallback 机制：ak.fund_etf_hist_sina()（Sina 源，最稳）-> 东财 K 线 API -> yfinance。实测 Sina 源 100% 可用。

2. yfinance 依赖问题

问题：本地 yfinance 版本依赖 websockets.asyncio，但 websockets 版本过低。

修复：pip3 install --upgrade websockets 升级到 15.0.1。

3. 净值数据列名

发现：fund_open_fund_info_em 返回列名为 ['净值日期', '单位净值', '日增长率']，无 累计净值 列（原 app.py safe_cols 包含它）。已适配。

4. QDII 净值滞后

发现：2026-07-10 查询时，最新净值为 2026-07-08（滞后 2 天）。回测中用 nav_{D-1} 作为决策基线，有轻微前视偏差（QDII 的 nav_{D-1} 实际在 D 日晚才公布），但可用 XOP 数据估算，偏差可忽略。

看板侧边栏 slider，0.50-1.00 可调，默认 0.94。参考基金最新季报实际股票仓位。

十、已知限制

  • 回测样本小：13 个月仅 5 次 3%+ 折价机会，统计显著性有限。需更长历史数据验证。
  • QDII 净值滞后：回测用 nav_{D-1} 作基线有轻微前视偏差（可用 XOP 估算消除，未实现）。
  • 无节假日日历：只处理周末，A 股/美股法定节假日不判断。
  • 申购赎回状态依赖第三方 API：东财移动 API 可能变更，以基金公司公告为准。
  • P5 推送无重试幂等：state.json 每日去重，但跨日状态变化可能漏推（如一天内暂停->开放->暂停）。
  • 未实现自动对冲：真正的无风险套利需要做空 XOP/原油期货对冲，普通投资者无此工具。
